# 26. わけではない

【**意味**】：はっきり～とは言えない

【**接続**】: 普通形 / [ナ/N+な]　+　わけではない / わけじゃない

- 世界中に「君のことが好きだ」と叫べない**わけではない**。でも、誰の目にも明らかだ。

# 27. ながら

【**意味**】：～けれども / aunque

【**接続**】: 

V~~ます~~/な/イ/N +　ながら(も)　<br> な/N　+　でありながら(も)

- 「いいえ」と言い**ながら**、その瞳はすべてを語(かか)っている。　

# 28. かわりに (1)

【**意味**】：　～はいいところと、悪いところがある

【**接続**】: <br>
普通形 + かわりに<br>
イ + かわりに<br>
ナ + な／である + かわりに

>*Los sustantivos (N) no pueden usarse directamente. (※Nは使えない)*

- 君を幸せにする。**そのかわり**、君のすべての愛を僕にください。

# 29. 反面

【**意味**】：　～なところがあるが、反対に⋯
> *Una situación tiene dos aspectos, **NO** se usa para contrastar dos cosas distinas.*

【**接続**】: <br>
普通形 + 反面 <br>
イ + 反面 <br>
ナ + [な/である] + 反面 <br>
N + [の/である] + 反面

- 君に私の人生も時間もすべてを捧(ささ)げた**反面**、私は自分のために生きる時間を失(うしな)った。

# 30. ようがない

【**意味**】：～する方法がない

【**接続**】: V~~ます~~ + ようがない

- 君の軌道に入った瞬間、もう君の引力から逃げようがない。

軌道(きどう) = （órbita）<br>
引力(いんりょく)（gravedad/atracción）

# 31. がたい

【**意味**】：～するのが、難しい

【**接続**】: V~~ます~~ + がたい

二つの明星、二つの心、一つの気持ち、もう忘れがたい、この人生を(よ)。

二つの明星(みょうじょう)、二つの心、一つの気持ち (desae)、もう忘れがたい、この人生を(よ)。

二つの明星、二つの心ga、一つの気持ちni nareba、もう忘れがたい、この人生を(よ)。

# 32. ずに

【**意味**】：～しないで

【**接続**】: V~~ない~~ + ず(に)

※しない → せず(に)

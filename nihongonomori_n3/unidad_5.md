# 34. くらい

【**意味**】： ～と同じ程度だ　(例を出して、自分の気持ちを話す)

【**接続**】: 普通形 / [ナ+な]　+　くらい/ぐらい

昔歩いてた道で、信じられないくらいまた歩く、景色が変わったのだろうか、僕の方か。

# 35. ほど

【**意味**】： ～と同じ程度だ　(「～くらい」よりかたい表現)

【**接続**】: 普通形 / [ナ+な]　+　ほど

目を上げると、遠くで、見えないほど、君が、輝いている。

# 36. だらけ

【**意味**】： ～がたくさんある　(悪いことや、汚いもの)

【**接続**】: N　+　だらけ

君に出会う前に、色のない日だらけだった。今は、絵のように、色合いに富んでいる。(色合いに富んだ日々だ。)
Kimi ni deau mae ni, iro no nai hi darake datta. Ima wa, e no yō ni, iroai ni tonde iru.

# 37. やすい

【**意味**】： 簡単に～できる

【**接続**】: V~~ます~~ + やすい

君には惚れやすい、性格も可愛さも１００点だから。
kimi ni horeyasui, seikaku to kawaisa ha 100 ten dakara.

# 38. はず

【**意味**】：「はず」は、理由があって、そうだと思うときに使います。

【**接続**】: 普通形 / [[ナ+な / N+の] + である] + はず(だ)

言ったはずだけど、も一回言う。君が好きだ。
